# Changelog

## 1.0.0 — In preparation

First public release, pending final release checks.

- Build an offline Steam screensaver from animated SteamGridDB artwork, with previews and installation from the app.
- Add installed or uninstalled library games, manual search, bulk selection and top-100 options. Exclude Steam runtime components.
- Choose animations and separate still artwork, with four artwork positions and adjustable Original / 16:9 / 16:10 framing.
- Offer optional 24/30 fps processing, live preparation progress and pause/resume.
- Include media cleanup, local JSON diagnostics and recovery after interrupted work.
- Provide SteamOS, Linux and Windows x64 packages, plus a macOS Apple Silicon DMG and ZIP. English and French interfaces are included.

Windows/Linux native testing and animation processing improvements remain priorities. See [validation](docs/VALIDATION.md) and the [1.0.0 release checklist](launch/READINESS.md).
