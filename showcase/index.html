Demo and setup

Animated SteamGridDB artwork as a Steam screensaver. The video shows the result, batch preparation, settings and playback inside Steam on macOS.

1 min 29 s · 1080p · music: Song Of The Forge by Scott Buckley · Music license and credits. Batch preparation is explicitly accelerated 8×. Artwork playback is real time; source animation quality varies.

Apply it in Steam

  1. In the app: choose games, Prepare, check Preview, then Install in Steam.
  2. In Steam Big Picture → Settings → Customization → Screensavers, select steam-animated-screensaver. Test Preview. SteamOS Gaming Mode has the same Customization section.
  3. Quit Steam completely. In the app, open Settings → Automatic start in Steam, start with 5 minutes and apply.
  4. Reopen Steam in Big Picture or Gaming Mode. The app can be closed. Use Update / Repair after later changes.

Some battery-equipped machines outside Gamescope are missing Steam’s delay controls. The app provides the setting, with a backup and a closed-Steam check. Your OS screensaver and lock settings are separate.

Help test it

SteamOS and macOS have received the most hands-on attention. Windows and Linux need more testing inside the actual Steam client. Help with animation smoothness, processing speed and reliability is welcome.
