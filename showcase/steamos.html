On SteamOS

  1. In Desktop Mode, extract the SteamOS archive and run install.sh.
  2. Choose games, Prepare, Preview, then Install in Steam.
  3. Return to Gaming Mode → Settings → Customization → Screensavers. Select steam-animated-screensaver and try Preview.
  4. Set the inactivity delay in Steam’s Power settings. Start with five minutes.

Gaming Mode already exposes its delay controls. The app’s extra setting helps outside Gamescope on battery-equipped machines, where Steam currently hides those controls.
